\# Smart IoT Logistics \& Parcel Tracking



\## Про проєкт

Цей репозиторій містить наскрізний проєкт розробки програмної системи "Smart IoT Logistics \& Parcel Tracking" (Сервіс логістики та трекінгу), що виконується в рамках дисципліни «Інженерія програмного забезпечення».



\*\*Smart IoT Logistics \& Parcel Tracking\*\* — це хмарна система моніторингу переміщення вантажів у реальному часі. Проєкт передбачає проєктування системи з прийманням GPS-телеметрії, розрахунком маршрутів та сповіщенням клієнтів. Результати роботи поетапно нарощують підсумковий документ Architectural Design Document (ADD).
